# S2 — Enrichment

**Theme:** a new plant fills in its own summary and care, with sources.

## Exit criterion

> A new plant auto-fills summary and care with sources in under 60s.

**Met mechanically, and thinner than it sounds.** Enrichment is at most five
calls per species (Wikipedia 1, Wikidata 1–2, USDA 2), with Wikipedia first so
Wikidata gets the item id rather than searching again; a test pins that budget.
The Specimen page shows the result with every citation and confidence attached.

What it fills in is the caveat — see below.

## Shipped

**D — Botany.** Wikipedia, Wikidata and USDA connectors; Perenual written but
never constructed without a key (ADR 0007), with its key redacted from
citations. Cited care synthesis, toxicity, and a one-command re-recorder for
every payload. 175 tests, none touching the network.

**J — Feature UI.** The Specimen page at `/specimen/:id/<facet>` with the
Register, Tending and Compendium facets, cross-linked to each other and to the
Journal that K builds in S8. 59 new tests; 261 web tests in total.

**A — Integration.** ADRs 0011 and 0012; the botany router mounted; the
contract at 1.1.0; three broken CI mechanisms fixed (below).

## The finding that matters

**USDA publishes measured characteristics for very few plants, and for none of
our eight fixture species.** D checked all eight; all return empty, including
*Podophyllum peltatum*, a well-known North American native. Only *Abies
balsamea* among the recorded species has a populated record, which is why it is
in the recorder's list at all — without it the minimum-temperature, pH, light
and toxicity parsers would be tested against nothing.

So for the fixture species, `water_k_c`, `min_temp_c`, `water_interval_days`
and `light_label` come back `value: null, confidence: unknown, source: null`.
That is ADR 0007's predicted coverage gap arriving, and under ADR 0010 — no
soil probe, the water balance alone deciding when to water — it is the gap that
has to stay visible.

D declined the obvious shortcut. USDA publishes a *Moisture Use* adjective
(Low/Medium/High); mapping it to a numeric crop coefficient would have filled
the field with a plausible number, and a test now pins the refusal. Wikipedia
contributes prose only — no number is read out of a sentence. A field nobody
stated gets no value, not a default; the engines' own fallbacks
(`float(species.water_k_c or 0.6)`) are documented assumptions, not facts about
the plant, and the worker does not launder them into one.

**Also missing:** USDA PLANTS has no hardiness zones in its API. The brief
expected zones from it; the service does not have them.

**Toxicity has one documented exception to source precedence:** a source
claiming toxicity outranks a source denying it, and the citation then points at
the source that made the claim. Confidence drops a step to record the
disagreement. Under-reporting is the dangerous direction for a safety flag.

## What went wrong

**The S0 fixtures cited the wrong species, eleven times.** J noticed one — the
snake plant's cold tolerance citing a *Monstera* record — and the audit found
ten more, including the mandrake's `toxic_to_children` citing a Monstera
article. A toxicity claim for a seriously poisonous plant, supported by a
citation about a different plant, is precisely the failure ADR 0004 exists to
prevent, and it sat in the seed data every test reads.

A second class of error came with it: POWO and GBIF are nomenclatural
authorities that publish names, synonymy and distribution, and no care value at
all — yet they were cited for `light_label` and `min_temp_c`.

The fixture tests did not catch either, because they only asserted that a
`source_id` existed in `sources.json`. Three guards now cover it: a citation
must name the species it is cited for, a source may only be cited for fields it
actually publishes, and a name-addressed URL must point at the right plant.
Reintroducing the mandrake citation fails the first.

**`main`'s image build had never passed — not once, since the S0 merge.** Both
Dockerfiles installed the project before copying its source, which cannot work.
Nobody saw it because the job was gated to `main`, so it only reported after a
merge: five merges in a row landed on a red build. The job now runs on pull
requests.

**`main` was red twice more**, both mine. Once when the botany router mount
made `api/app/main.py` import `workers.botany` and nothing guaranteed the
repository root was importable — I had verified with `python -m pytest`, which
prepends the working directory to `sys.path`, where CI's bare `pytest` script
does not. The same commit passed locally and errored 21 tests in CI.

That one has a sequel worth recording: D's `workers/botany/tests/conftest.py`
had been inserting the repository root itself, so `pytest tests api workers`
loaded it and looked healthy while `pytest tests/contract` did not and failed.
A repository-wide path problem presented as one workstream's. D removed the
duplicate once the root `conftest.py` existed (#11).

## Contract gaps carried into S3

1. **A specimen override cannot be read back.** `SpecimenUpdate` accepts
   `water_k_c_override`, `water_interval_days_override` and
   `min_temp_c_override`; `Specimen` carries no matching fields, so the API
   takes a correction and then reports the sourced value again. ADR 0004 says a
   user edit wins over all sources, which the contract cannot currently express
   on a read. J declined to hide it client-side and says so on the page.
2. **`CareValue.source` has no null variant.** ADR 0004 requires the row to
   exist with no source; the merged endpoint returns `source: null`; L's test
   asserts it; the schema cannot validate it.
3. **The Compendium has nowhere for "lore and uses"**, which the plan lists.
4. **`web/src/lib/api/client.ts` belongs to no workstream**, so nobody may
   extend the shared API client. The app now has two typed clients as a result.

## Known gaps for L

- No outdoor fixture specimen has an uncited `water_k_c` — exactly ADR 0010's
  worst case, where the model is the sole authority *and* nobody attested the
  coefficient. J verified that path by moving the snake plant outdoors in a
  mock; a fixture specimen in that state would put it under the scenario suite.
- Wikimedia throttled D's recording session (`403 Please respect our robot
  policy`), so Wikipedia and Wikidata are recorded for *Monstera deliciosa*
  only; the rest fall back to the frozen fixtures. D did not retry into a policy
  asking us not to, and wrote no stand-in. Re-run the recorder when it clears.
