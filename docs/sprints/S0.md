# S0 — Charter

**Theme:** freeze the contract and make every workstream able to run the whole
stack before its dependencies exist.

## Exit criterion

> Every agent runs the full stack locally on mocks.

**Met.** `make dev` brings up Postgres/TimescaleDB, Redis, Mosquitto, the API
and the web app. With `MOH_MOCK_MODE=true` (the default) the API answers every
read endpoint in the contract from `fixtures/`, so no workstream waits on
another and none needs credentials to see a working page.

## Shipped

**A — Architect.** Schema v1 (25 tables, 3 hypertables, 3 continuous
aggregates), OpenAPI v1 (32 paths, 44 schemas, each operation tagged with its
owning workstream), the MQTT topic contract, and ADRs 0001–0006.

**B — Platform.** Monorepo layout, `Makefile`, the dev compose stack, API,
worker and web images, the CI pipeline, and `scripts/check_ownership.py`, which
enforces rule 2 from the branch name.

**I — Design system.** Tokens for both themes (`parchment`, `greenhouse`), a
1.25 modular type scale, the app shell and navigation, and `StatusPill`, the
component that makes the themed/plain pairing structural rather than a
convention.

**L — QA.** Eight species with cited care profiles, twelve specimens, seven
locations, 30 days of baseline weather, three scenarios (drought, storm,
frost), and 67 tests: contract, schema, fixture, mock-stack, engine and
ownership.

## Decisions taken

ADR 0001 (record ADRs), 0002 (stack), 0003 (contract-first with directory
ownership), 0004 (no invented plant facts — citations and confidence), 0005
(wizarding botany without franchise assets). ADR 0006 lists the five open
decisions with a cheapest-to-reverse default for each, so no sprint is blocked
waiting for an answer.

## What the tests caught

Three defects, all real, all before any feature code existed:

1. `openapi.yaml` declared a query parameter named `on`, which YAML 1.1 parses
   as the boolean `true`. The contract was invalid and nothing would have
   generated from it.
2. The border tokens failed WCAG AA at 1.66:1 and 1.87:1 against their
   surfaces. Borders are the component boundary and need 3:1; both themes were
   corrected.
3. Two scenario fixtures promised engine behaviour the physics does not
   produce — lavender was expected to need water in a fortnight it comfortably
   survives, and the frost scenario opened already below basil's threshold, so
   it tested no trend. Both scenarios were rebuilt; the engine was not bent to
   fit them.

## Carried into S1

- Only read endpoints are implemented. Every write is listed in

  sprint that removes it — that list is the project's real progress bar.
- `mypy` runs advisory in CI until S1.
- Harbor push needs registry credentials (B, S1).
